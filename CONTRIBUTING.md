# Contributing to HVAC AI Receptionist

Thank you for your interest in contributing!

## How to contribute

1. Fork this repository.
2. Create a new branch for your change.
3. Make your changes.
4. Test your changes.
5. Commit your changes with a clear message.
6. Open a Pull Request.

## What you can contribute

- Bug fixes
- New features
- UI improvements
- Documentation
- Tests
- Performance improvements
- Accessibility improvements
- Security improvements

## Code quality

Please keep contributions:

- Simple and maintainable
- Well documented
- Secure
- Free of API keys and other secrets

## Reporting bugs

When reporting a bug, include:

- What happened
- What you expected to happen
- Steps to reproduce the problem
- Browser/device information when relevant

## Feature requests

Explain:

- What feature you would like
- Why it would be useful
- How you think it could work

## Pull Requests

Please describe what your Pull Request changes and why.

Thank you for helping improve HVAC AI Receptionist!

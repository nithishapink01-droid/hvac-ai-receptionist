# HVAC AI Receptionist

An open-source AI receptionist for HVAC businesses.

## What it does

HVAC AI Receptionist is designed to help heating and cooling businesses handle customer inquiries 24/7.

Planned features include:

- 🤖 AI customer conversations
- 📞 Customer inquiry handling
- 📝 Lead capture
- 🔧 HVAC service requests
- 📅 Appointment requests
- 🚨 Emergency-service information
- 💬 Conversation history
- 🏢 Business settings
- 📊 Lead management

## Project Status

🚧 Early open-source development.

The current version is a basic working web interface. More features are being developed.
